# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's **Report a
vulnerability** option under the repository's Security tab. If it is
unavailable, contact the repository owner privately through their GitHub
profile.

Include the affected version, reproduction steps, impact, and any suggested
fix. Never include real personal data or secrets. You should receive an
acknowledgement within seven days. Details will remain private until a fix is
available or disclosure is coordinated.
